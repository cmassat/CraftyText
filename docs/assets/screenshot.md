# Built on MarkText. Tuned for how you work.

**CraftyText** is a fork of [MarkText](https://github.com/marktext/marktext) — the same distraction-free WYSIWYG editor, with the workflow features power users kept asking for. Still MIT, still [CommonMark](https://spec.commonmark.org) and [GFM](https://github.github.com/gfm/). ✍️

| What the fork adds       | Why it matters                                 |
| ------------------------ | ---------------------------------------------- |
| **Multiple folders**     | Every repo and notes vault in one sidebar      |
| **Cross-folder search**  | One query, deduped hits, expand/collapse all   |
| **Source toggle**        | Raw markdown one click away in the title bar   |
| **Retro 70s · Neon 80s** | Two new theme families — **37** to choose from |

> Plus a responsive menu bar, restored folder sessions, and a sidebar that finally has some breathing room.
