## About

CraftyText is a fork of [MarkText](https://github.com/marktext/marktext) with additional enhancements and its own branding. The project remains licensed under MIT and preserves the original MarkText copyright notices.

## Features

- Realtime preview (WYSIWYG) with a clean interface for distraction-free writing.
- Support for [CommonMark](https://spec.commonmark.org), [GitHub Flavored Markdown](https://github.github.com/gfm/), and selected [Pandoc Markdown](https://pandoc.org/MANUAL.html#pandocs-markdown) behavior.
- Markdown extensions including math expressions (KaTeX), front matter, diagrams, and emojis.
- Paragraph and inline style shortcuts.
- Export to **HTML** and **PDF**.
- Built-in light and dark themes.
- Editing modes including **Source Code mode**, **Typewriter mode**, and **Focus mode**.
- Paste images directly from the clipboard.

## Download and Installation

Prebuilt artifacts are expected to use the CraftyText names generated by the desktop package:

- macOS: `craftytext-mac-(arm64|x64)-<version>.dmg`
- Windows installer: `craftytext-win-(x64|arm64)-<version>-setup.exe`
- Windows portable zip: `craftytext-win-(x64|arm64)-<version>.zip`
- Linux: `craftytext-linux-<version>.(AppImage|deb|rpm|snap|tar.gz)`

Until public releases are published, build from source.

## Development

Use Node `>=20.19.0` and pnpm `>=10`.

```bash
pnpm install
pnpm dev
```

Common commands:

- `pnpm dev`: start the desktop app with `electron-vite dev`.
- `pnpm build`: build the desktop app.
- `pnpm test`: run the desktop Vitest suite.
- `pnpm lint`: run ESLint.
- `pnpm typecheck`: run desktop type checking.
- `pnpm check`: run lint and typecheck.
