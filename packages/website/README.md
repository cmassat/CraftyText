# CraftyText Website

This package contains the CraftyText documentation and website.

## Development

```bash
pnpm --filter craftytext-website dev
```

## Build

```bash
pnpm --filter craftytext-website build
```

The docs search index is generated by:

```bash
pnpm --filter craftytext-website docs:index
```

## Deployment

Cloudflare/OpenNext configuration lives in `wrangler.toml`. The production domain is
`https://craftytext.com`; connect that custom domain to the `craftytext-website` Worker in
Cloudflare.
